# EcoTrade prototype

Direction selected by the user: dark green and paper colours, with simple search, personal listings and forms for a student demo. Interface copy is in English, and listing photos come from student uploads.

Reading this as: a study-material sharing portal for university students, in a paper catalogue visual language, ENERGY 1 / RHYTHM 2 / MOTION 1.

- Dark green connects the reuse theme to primary actions; warm paper backgrounds suit books and long descriptions. Light is the initial theme selected for this direction; a dark theme is available for user preference.
- Georgia headings echo book typography. Segoe UI body text matches the Windows demo environment and keeps form labels readable without downloading fonts.
- Catalogue rows prioritise category, title, condition, owner and sharing type. Forms use a narrower reading width; detail pages put ownership actions beside the description.
- Larger space separates page headings, search and results; tighter space groups labels and fields. Desktop rows become stacked entries on phones.
- Colour labels communicate listing type and status using text. They are functional metadata, not promotional badges.
- Rounded corners are limited to fields and action surfaces. Short colour transitions signal interaction. The photo carousel uses native scrolling and numbered links, with smooth scrolling only when motion is allowed.
- Navigation includes Messages for students and Admin dashboard for administrators. Admin overview shows database counts, with separate pages for operational tasks.
- Listing forms group item details, photos and sharing method. Native radio inputs make condition and sharing choices visible without a dropdown.
- Chat puts the participant and listing in separate rows so the subject stays clear before the first message. Profile photos use uploaded images or an initial beside the participant's name.
- Loading text appears during navigation and submission. All forms work without JavaScript; theme selection and loading feedback are progressive enhancements.
